# my-own-web-OS
This is my own website operating system. It is created to have 3 apps: a notepad, a calculator and a shopping list. The notepad helps to store information about my daily thoughts. A calculator helps me to perform calculations much more easily. A shopping list in case I need to keep track of things I order. 
You must double click to access an app. There is a clock at the top in a standard 12-hour time. It also has a welcome screen to identify my webOS as my own.
Every webOS can open and close on it's own.
