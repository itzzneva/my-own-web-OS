# my-own-web-OS
This is my own website operating system. It is created to have a notepad. In the notepad, I create a space to share my thoughts.
The welcome screen includes a picture with a blue sky and details the purpose of my OS.
There is a photo gallery with a pen, calculator and shopping list as my supplied.
There is a clock at the top of the page to track the time.
The theme is bright and colourful to make it more visually appealing for the person. 
It has a red button to close each tab.
There is a border around each app. Each app has a description beneath it so the user knows what they are clicking on.
